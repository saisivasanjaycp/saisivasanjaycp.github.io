Featured project

APEX

AI-Assisted Playwright Automation Framework

I designed and developed an AI-assisted Playwright framework that converts Testplanner-generated Markdown test plans into executable automation scripts. It reuses existing automation assets first and generates new scripts only when nothing suitable exists.

  • TypeScript
  • Playwright
  • MCP
  • AI-assisted workflows
  • JSON knowledge store
  • Istanbul

EMart pilot results

Results from applying APEX to the EMart pilot.

91.3%Reuse or composition decisionsMeasured in pilot
53.7%Locator reuseMeasured in pilot
~70%Reduction in automation effortEstimate, not measured

Reuse figures describe how automation assets were sourced during the pilot. They are not test pass rates or code coverage.

The problem

Turning each new test plan into automation usually means rewriting steps, page methods and locators that already exist in the suite. Generating everything with AI repeats that duplication, adds token cost and produces inconsistent code. APEX checks what already exists before writing anything new.

How a test plan becomes a running test
01/05

  1. markdown test plan

    Test plans generated by Testplanner are the input.

  2. semantic test matching

    Finds existing tests with the same intent, even when the wording differs, using deterministic text representations and a JSON knowledge store.

  3. reuse, compose or generate

    1. Reuse existing tests, steps, page methods and locators
    2. Compose new scenarios from available assets
    3. Generate new scripts only when necessary

  4. playwright execution

    Runs the suite with controlled self-healing, validation and write-action guardrails.

  5. reporting and coverage

    Token usage reports and Istanbul frontend line and function coverage.
